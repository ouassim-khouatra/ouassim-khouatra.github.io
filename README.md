# Portfolio — Ouassim Khouatra

Site statique : `index.html` (autonome) + `cv/CV_Ouassim_Khouatra.pdf`.

## Mise en ligne sur GitHub Pages

1. Créer un dépôt **public** nommé exactement `ouassim-khouatra.github.io`.
2. Y déposer `index.html`, le dossier `cv/` et ce `README.md`.
3. Settings → Pages → Source : *Deploy from a branch*, branche `main`, dossier `/ (root)` → Save.
4. Après une à deux minutes : https://ouassim-khouatra.github.io

Le bouton « Voir mon CV » pointe vers `cv/CV_Ouassim_Khouatra.pdf` : remplacer ce fichier pour mettre le CV à jour.
